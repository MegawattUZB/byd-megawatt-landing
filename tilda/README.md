# Лендинги в Тильде (byd.megawatt.uz)

Скрытые страницы на основном сайте под рекламу. Из меню и с других страниц сайта на них ссылок нет.

Файлы в этой папке собираются командой `python3 tools/build.py`. Вручную их не правят.

| Файл | Страница в Тильде (пример адреса) |
|---|---|
| `chazor.html` | `byd.megawatt.uz/promo-chazor` |
| `song-plus.html` | `byd.megawatt.uz/promo-songplus` |

Картинки, шрифты, CSS и JS загружаются с jsDelivr из репозитория GitHub `MegawattUZB/byd-megawatt-landing` (адрес задан в `SITE["cdn"]` в `tools/build.py`).

## Как создать страницу

1. Тильда → сайт BYD Megawatt → «Создать новую страницу» → пустая страница.
2. Добавить блок **T123** («Другое» → «HTML-код»). В «Контент» вставить **всё** содержимое файла (`chazor.html` или `song-plus.html`).
3. Настройки страницы:
   - **Главное**: заголовок и описание (готовые тексты ниже); адрес страницы — например `promo-chazor`.
   - **SEO**: включить «Запретить индексацию страницы поисковыми системами».
   - **Соцсети (Facebook / Telegram)**: заголовок и описание те же; картинка — загрузить `assets/img/og/chazor.jpg` или `song-plus.jpg` из этого репозитория.
   - **Дополнительно**: Header и Footer — «не показывать», чтобы не выводились шапка и подвал сайта.
4. Опубликовать. Ссылки на эту страницу в меню и в блоках сайта **не добавлять**.

## Ссылки для рекламы

Работают те же параметры, что и раньше, например `?term=12`, `?down=25`, `?mode=credit&term=60`, `&lang=uz` (подробно — в корневом README).

## Аналитика

Своих счётчиков лендинг не подключает: на сайте уже стоит GTM (`GTM-P6XNZCZ9`). События `call_click`, `calc_used`, `smart_banner`, `lang_switch`, `main_site_click` уходят в `dataLayer`. В GTM для них нужно настроить триггеры «Пользовательское событие».

## Как обновлять

- **Поменялись цены, ставки или тексты** (`tools/build.py`): пересобрать и заново вставить код файла в блок T123, затем опубликовать страницу.
- **Поменялись файлы в `assets/`** (картинки, CSS, JS): закоммитить изменения, поставить новый тег (`v2`, `v3`…), прописать его в `SITE["cdn"]`, пересобрать и заново вставить код в T123. Старый тег продолжает работать, поэтому страницы не ломаются, пока код не заменён.
