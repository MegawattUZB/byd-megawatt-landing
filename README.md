# BYD Megawatt — лендинги «Рассрочка 0%»

Одностраничники под таргетированную рекламу. Воронка: реклама → лендинг → звонок на +998 78 113 70 88.

| Страница | Путь |
|---|---|
| BYD Chazor (55KM Luxe, 120KM Flagship) | `/chazor/` |
| BYD Song Plus DM-i Champion (110KM, 150KM Flagship) | `/song-plus/` |
| Выбор модели | `/` |

Узбекская версия — тот же адрес с `?lang=uz` (например `/chazor/?lang=uz`). Удобно давать в рекламу на узбекском.

## Смарт-баннеры: текст под объявление

Заголовок, подзаголовок, платёж на первом экране и калькулятор подстраиваются под параметры ссылки. Платёж и сноска считаются по реальной таблице ставок.

| Объявление про… | Ссылка | Что увидит клиент |
|---|---|---|
| рассрочку на 1 год | `/chazor/?term=12` | «BYD Chazor в рассрочку 0% на 12 месяцев», платёж от 8 530 000, калькулятор на 12 мес |
| рассрочку на 18 мес | `/chazor/?term=18` | то же под 18 месяцев |
| маленький первый взнос | `/chazor/?down=25` | «Первый взнос 25% и рассрочка 0%», до 18 месяцев |
| конкретную комплектацию | `/chazor/?term=24&trim=120` | расчёт только по 120KM Flagship |
| кредит на 5 лет | `/song-plus/?mode=credit&term=60` | «в кредит на 60 месяцев», ставка от 3,5% |
| на узбекском | добавить `&lang=uz` | всё то же на узбекском |

Параметры можно передавать и через UTM: `utm_content=term12`, `utm_content=down25`, `utm_content=credit_term60`.
Если на выбранный срок рассрочки 0% нет (например 48 мес), страница честно покажет кредит с реальной ставкой.
Комплектации: Chazor — `55`, `120`; Song Plus — `110`, `150`.

## Как менять цены, ставки, тексты, видео

Всё в одном файле — `tools/build.py`:

- `SITE` — домен, телефон, ID счётчиков (GTM / GA4 / Meta Pixel / Яндекс.Метрика), ID роликов YouTube;
- `RATES_*` — таблицы ставок (взнос × срок);
- `MODELS` — цены комплектаций, тексты RU/UZ, преимущества, сравнение;
- `COMMON` — общие тексты RU/UZ, FAQ, адреса, пример диалога с менеджером;
- `REVIEWS` — реальные отзывы клиентов (пока пусто — блок скрыт).

После правки пересобрать страницы:

```bash
python3 tools/build.py
```

## Что отслеживается

Клик по любой кнопке звонка отправляет событие `call_click` (с местом клика, языком и — для кнопки калькулятора — выбранным расчётом) во все подключённые счётчики. В Meta Pixel это стандартное событие `Contact`. Дополнительно: `calc_used`, `video_play`, `lang_switch`.

## Публикация

Статические файлы без сервера: подходит любой хостинг (GitHub Pages, Netlify, обычный хостинг). Загрузить в корень всё, кроме папки `tools/`.

Заголовки — фирменный Conthrax (SemiBold / Bold / Heavy), подключён из `assets/fonts/` в формате woff2 (кириллица + латиница, ~27 КБ на начертание). Для веб-использования шрифта нужна веб-лицензия Typodermic.
